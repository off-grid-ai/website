# Making OGAM and OGAD free forever

Platform-specific image carousels for the Off Grid AI founder note.

## Deliverables

- `linkedin/`: 10 PNG slides at 1080 x 1350
- `x/`: 4 PNG cards at 1600 x 900
- `index.html`: the single editable source for both sets
- `render.mjs`: deterministic Playwright renderer

## Render

From this directory:

```bash
node render.mjs
```

The renderer uses the Playwright installation from the sibling Console repository.

## Suggested LinkedIn post copy

OGAM and OGAD are going to be free forever.

The Off Grid AI suite has crossed 120,000 downloads. If private, on-device AI is going to reach population scale, I do not think the consumer layer can depend on who can pay every month.

The work still needs to be funded. I am betting that the enterprise side can do that without putting the consumer products behind a paywall.

OGAC is the enterprise product: about 50 open source services, connected through one integration layer, covering data, models, policy, guardrails, evals, audit, applications and fleet operations.

The goal is simple. Connect the systems an enterprise already has. Make the safe path reusable. Let anyone inside the organization create useful apps and agents without rebuilding security, governance and compliance every time.

I am looking for critique and a small number of design partners. I will handle discovery, setup and the first implementation. Commercial terms start only after the PoC works and the agreed capability is signed off.

If you lead AI, data, risk, operations or transformation inside an enterprise, I would value your perspective or an introduction to the right team.
