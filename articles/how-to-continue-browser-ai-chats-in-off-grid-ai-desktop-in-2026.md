You can start a question in the Off Grid AI browser extension and continue its saved conversation in OGAD (Off Grid AI Desktop). To continue on a phone, use the separate device-sync setup in OGAM (Off Grid AI Mobile).

The extension's approved desktop connection and the phone's sync connection serve different purposes. Pairing a browser does not automatically pair a phone. Both connections must be ready before you expect the same conversation to appear across all three places.

## Start with a conversation worth continuing

Suppose you read a project page in Chrome and ask for a summary. Later, you want to expand that summary on the desktop, then review it on your phone before a meeting. Keeping the same conversation saves you from rebuilding the question and its follow-ups.

This is a saved-conversation workflow. It does not mean every device has the same live browser page, the same model loaded, or access to the same website account. A phone can show a saved answer even when the website source needs a separate sign-in.

## Connect the browser to OGAD

Install the [early-access extension](https://getoffgridai.co/browser-extension/) and use a current OGAD beta. Open **Settings > Desktop**, select **Pair with desktop**, compare the six words, and approve the matching request on the computer.

Choose a local model if you want the browser's model work to run on your computer. Prepare the desktop access required by the paired workflow and Pro tools. Keep OGAD running while you send the first request.

Each browser tab can have its own conversation. Start with one tab so it is clear which conversation you are following. A new tab or a new-chat command can create a different conversation instead of continuing the one you intended.

## Check the browser-to-desktop handoff

1. Ask a distinctive question in the extension, such as a summary of one named project page.
2. Wait for the answer to finish.
3. Open OGAD's conversation history and find that conversation.
4. Check the original question and answer, then add one follow-up on the desktop.
5. Return to the extension and confirm that you are looking at the same conversation.

Use a specific phrase in the first message so you can find it in history. “Summarise the Northwind launch checklist” is easier to distinguish than several conversations all called “Hello”.

The desktop owns the saved transcript. Closing the side panel does not necessarily cancel a running desktop task or delete the conversation. Use the explicit stop or delete controls for those separate actions.

## Add the phone through device sync

Install OGAM and follow the **Devices** or sync setup for your desktop and phone. Approve the pairing on the required devices. Enable conversation sharing for the data you want to use.

For a local setup, put the devices on a usable local network. A network that isolates guests from one another can block discovery or transfer even when both devices show a Wi-Fi connection. Keep both apps available while the first sync completes.

Open the conversation list on the phone and find the distinctive first message. Check that the later desktop follow-up is present too. This confirms that you have a current copy, rather than an older conversation with a similar title.

## Know what carries over

| Item | What to verify |
|---|---|
| Question and reply | Both appear in the intended conversation |
| Later follow-up | Sync has delivered the latest turn |
| Attached image | The attachment is available, not only its text label |
| Website context | Saved context may be older than the current page |
| Next model response | The device has a working local or remote model route |

Saved content and live inference are separate. Continuing with a new question on the phone needs the phone's own model or an enabled remote model connection. Sync alone does not turn on a desktop inference server for the phone.

## Keep the source current

If the conversation concerns a live portal, recheck the page before relying on an old status. The saved answer describes the information read at that time. A later ticket update or changed deadline will not become true in the old answer automatically.

Ask a follow-up that names the new evidence: “This status changed today. Update the brief using the current page, and show what changed.” On a device that cannot access that page, supply the relevant current text or return to the connected browser.


## Clear a browser copy without deleting the Desktop chat

In the paired browser extension, open **Settings > General** and find **Browser chat cache**. Its **Clear** control removes this browser's cached copies. Your conversations remain in OGAD, and a later sync can bring them back. This is useful for clearing local browser storage; it is not a permanent deletion from the Desktop library.

Deleting an individual conversation from browser history is different. The extension asks Desktop to delete the saved conversation and asks you to confirm. Read the conversation title before confirming. Renaming and searching history also use the Desktop-owned records.

| What you want | Use |
| --- | --- |
| Remove this browser's cached copies | Browser chat cache > Clear |
| Remove a saved conversation | Its confirmed Delete action |
| Stop an active reply | Stop in the relevant chat |

Keep OGAD reachable when changing saved history. A disconnected panel cannot prove that Desktop accepted a deletion. Clearing a cache or deleting a chat also does not erase independent exports, screenshots, or backups.

## If the conversation is missing

Check which desktop the browser is paired with, then which desktop the phone is syncing with. Confirm that conversation sharing is enabled and that the relevant apps can communicate. Search by the distinctive message rather than only the generated title.

Do not create several duplicate chats as a first fix. Check the connection and the existing history first. This makes it easier to identify the saved conversation that contains the latest work.
