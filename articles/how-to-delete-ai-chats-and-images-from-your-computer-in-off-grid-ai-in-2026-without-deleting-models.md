## Choose the data you want to remove

The core controls in [OGAD 0.0.51](https://github.com/off-grid-ai/OGAD/releases/tag/v0.0.51) are available on Mac and Windows. They act on data stored by OGAD on that computer.

The two categories relevant here are:

| Category | What the cleanup covers |
|---|---|
| Chats | Conversations and messages, with their stored chat upload files |
| Generated images & artifacts | Generated image files, saved artifacts, and related thumbnails |

The second category is broader than pictures alone. If you have saved useful artifacts, copy the ones you need to another location before clearing it.

These are category-wide controls. **Clear** beside Chats is not a request to remove only the conversation currently on screen. Read the confirmation before you proceed.

## Keep anything you still need

Copy important text into a document or save a backup before cleanup. Save generated files you want to keep outside the category being cleared. Open those saved copies and check that they contain the material you need.

Deleting local data does not remove copies you already exported, shared, or stored in another backup. It also does not ask a remote service to erase material you sent to it. This guide covers the current computer's OGAD data.

## Clear chats and images separately

1. Open **Settings** and find **Data & privacy**.
2. Review **Your data on this device**.
3. Find **Chats** and select **Clear** if you want to remove all stored chats in that category.
4. Read and confirm the deletion prompt.
5. Find **Generated images & artifacts** and select **Clear** only if you also want that category removed.
6. Check the refreshed category counts and return to the relevant library or chat view.

Leave other categories alone if you only want these two removed. Saved screen captures, meeting data, and memory have their own cleanup controls.

Deletion is permanent in this workflow. It does not move the category into a recoverable trash folder inside OGAD.

## Keep your local models ready

The model files are separate from these chat and image categories. After cleanup, you can select an installed local model and start a new conversation without downloading that model again.

A useful check is to send one short prompt in a new chat after clearing the old chats. If you kept an image model and want a fresh image library, generate one new image when you are ready. New work will create new local data.

Keeping models is not the same as keeping the knowledge in a deleted conversation. The model still runs, but you must supply any removed source text again if a future task needs it.

## When you want a wider reset

The panel also offers **Delete all my data** and states that installed models are kept. That action is much broader than the two category buttons and has separate confirmations.

Use the category controls for a focused cleanup. Do not use a full personal-data reset when your goal is only to clear old chats or generated images.
