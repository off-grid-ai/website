## Give the assistant enough to write once

The **Draft an email reply** flow asks for the thread, reply outcome, required points, tone, and mail app. This is useful when you need to acknowledge a request, answer several questions, and keep a commitment accurate.

For example, your brief might say: “Find the email from Sam about the design review. Confirm that the review is Friday at 11:00, ask for the latest mockups, and keep the reply under 100 words. Do not promise a delivery date.” Supply real facts from the thread or your own decision.

## Prepare the first draft

1. Select a local text model and prepare a local Computer Use model in OGAD. Grant macOS Accessibility and Screen Recording permissions through **Settings > Setup & health** if needed.
2. Open **Assistant** and choose **Draft an email reply**.
3. Fill **Thread to find**, **Reply outcome**, **Required points**, and **Tone and length**. Set **Mail app** to the app you use.
4. Select **Start in chat**. Review any Computer Use request to act in the app, then watch it find the correct conversation.
5. Check that the reply remains in Drafts. Review the recipient, quoted context, facts, and attachments yourself before sending.

The preset explicitly asks the assistant to leave the reply unsent. If it finds the wrong thread, stop and add more precise sender, subject, date, or mailbox clues.

## Turn an incomplete request into a useful reply

A thread can ask several questions at once. Before launching the task, separate what you know from what still needs an answer. That gives the assistant a brief it can use without filling gaps for you.

| Part of the brief | Example |
|---|---|
| Thread clue | Sam's design review email, received this week |
| Decision already made | The review is Friday at 11:00 |
| Information to request | Ask for the latest mockups before the review |
| Promise to avoid | Do not commit to a delivery date |
| Finished result | An unsent reply under 100 words in the correct thread |

Use details you have checked. If Friday's date or timezone is unclear, resolve that before asking the assistant to draft a real appointment confirmation.

This approach is useful for a reply that needs judgment: acknowledge the request, answer the settled points, and ask one focused question about what remains. The model can handle wording while you remain responsible for the commitment.

## Review the draft as a reply, not a writing sample

Read the incoming message beside the draft. Check whether the reply answers each question and whether it changes the meaning of your brief. A polished paragraph can still say “we will deliver” where you only authorized “we will review.”

Confirm the recipient and thread too. Similar subject lines and forwarded messages can lead to the wrong conversation. If the draft refers to an attachment, check that it is actually attached and is the version you intend to send.

When you want a revision, name the difference: “Keep the confirmed review time. Replace the delivery promise with a request for the latest mockups. Leave the reply unsent.” Check the revised draft again before using the mail app's send control.

For a message that does not need app control, you can instead paste the text you want to share into a normal local chat and ask for reply wording. That produces text you copy yourself. Choose the route that matches the work: the preset helps operate the mail app; ordinary chat helps compose from supplied material.

## Find a contact without guessing an address

OGAD also has a native Contacts search tool on Mac. In chat, you can ask it to find a named contact before drafting. Allow macOS Contacts access if requested, and choose the right result when names match more than one person. Never treat a generated address as a verified contact.

## Does the email stay on the Mac?

With local task models, the AI processing can stay on the Mac. Your email account and mail app can still sync through their provider. A remote model changes the AI data path. This guide prepares a draft; sending an email uses the mail service.

If the assistant only returns suggested text, check the selected flow and Computer Use setup. If a thread is not downloaded, the mail app may need internet access to fetch it first.
