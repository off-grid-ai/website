This helps when you have several versions of a blog illustration, a story character, or a presentation graphic. The conversation holds the work around the image. The gallery gives you a faster way to browse the pictures themselves.

## Where are earlier AI images in OGAD?

Open **Generated images** from the chat toolbar to show the **Gallery**. Choose **Images**, then browse **This chat**, **Project**, or **All**. Select a thumbnail to open the image at a larger size.

The scope is the useful part:

| Scope | When to use it |
|---|---|
| This chat | You remember the conversation that produced the image |
| Project | You know which project it belongs to, but made images in several chats |
| All | You do not remember the conversation or project |

The Project option requires an active project. If you opened a general chat, choose the relevant project first or browse All.

This workflow is available in the core gallery in [OGAD 0.0.51](https://github.com/off-grid-ai/OGAD/releases/tag/v0.0.51). Browsing saved local images does not require generating another image or contacting a cloud model.

## Find the image by what you remember

Start with the narrowest scope you can identify. A project with five image conversations is easier to browse than every picture in the app. If you only remember the appearance, widen the gallery to All and look through the thumbnails.

For example, suppose you made several reading-lamp illustrations last week. One had the right open space for a blog heading, but you do not remember its exact prompt.

Open the blog project and choose Project in the gallery. Look for the lamp composition. When you find it, open the image and inspect the space, subject, and colors before deciding it is the version you meant.

If you remember the chat, return to it as well. The conversation can explain why you chose a version and what you asked to change. That context is often more useful than a generated filename.

## Keep the picture and its reasoning together

Use a separate project for work you expect to revisit. Generate images from conversations inside that project so the app can associate the results with it. This gives you a practical way to separate a story project from a blog or presentation.

You do not need an elaborate naming system. A clear project name and one brief note in the conversation can be enough:

> Keep this version for the opening slide. The subject is on the right and the left side has room for the title.

That note records the decision behind the image. When you return later, you can judge whether it still fits the current use instead of simply picking the newest thumbnail.

Image results can also show generation metadata such as dimensions, steps, seed, and model. Use that information when you want to compare settings. It does not replace the original image, and matching a seed on another runtime does not guarantee the same pixels.

## Getting started

Make one small image in a clearly named project, then check both ways of finding it. You will know where to look before your library grows.

1. Install [OGAD](https://getoffgridai.co/desktop/) and prepare a local image model.
2. Open or create a project for your work.
3. Generate an image in a conversation within that project.
4. Open **Generated images → Images → This chat**.
5. Switch to **Project**, then **All**, to see how the scopes change the list.

Choose an existing project and image if you already have some. There is no need to generate another result just to try the gallery.

## Why is an image missing from the current view?

A narrow gallery can be empty even when the image exists elsewhere in the app. Check All before assuming the file is gone. An image generated in a general conversation will not belong to a project merely because that project is open now.

If you received an image through device sync, its conversation can arrive before the file finishes transferring. Keep both devices connected and let the transfer finish, then reopen the image. Sync is a separate Pro workflow; local browsing alone does not require it.

The gallery shows supported images stored by the app. It is not a search of every picture on your computer. If you saved a different copy outside OGAD, look in the location where you saved it.

Deleted files also cannot be recreated by a gallery filter. Keep a separate backup of work that matters to you. A useful browsing view is not an independent archive.

## Return to the result instead of starting again

[Open OGAD](https://getoffgridai.co/desktop/) and choose one project you worked on before. Browse its images, open a version you want to keep, and add one sentence explaining its purpose in the conversation. The next time you need it, you will have both the picture and the reason you chose it.
