LOCAL API

One local endpointthat speaks OpenAI.

Point any OpenAI client at http://127.0.0.1:7878/v1 and it works. No key. Chat, vision, image, audio, and embeddings, all on one local server.Point any OpenAI client at http://127.0.0.1:7878/v1 and it works. No key. Chat, vision, image, audio, and embeddings, all on one local server.

from openai import OpenAI
client = OpenAI(base_url="http://127.0.0.1:7878/v1", api_key="not-needed")
print(client.chat.completions.create(
    model="local",
    messages=[{"role": "user", "content": "Hello"}]
).choices[0].message.content)
